# A Few Questions Before the Workshop

Please tick any choices that fit your experience; it is fine to leave a question blank. These answers help the instructor prepare examples for the group. See the [setup instructions](PRE_SESSION_CHECK.md) before the workshop.

1. **Which of these sound like your regular work?**
   - Organizing data, making tables, or analyzing results in tools such as Excel, Prism, or Geneious.
   - Editing files in applications such as RStudio, VS Code, or PyCharm.
   - Running tools or commands in a terminal.

2. **How do you keep track of changes to research files?**
   - Renamed copies, such as `analysis_v2`, `analysis_final`, or `analysis_final_revised`.
   - Version history in a shared document or cloud storage, such as Google Drive or Word.
   - Git or another version-control system.

3. **How do you usually work on files with other people?**
   - Sending revised copies by email or chat.
   - Working together in a shared Google Doc, Word document, or other cloud document.
   - Collaborating through a shared GitHub repository or another version-control system.

4. **How have you used an AI coding assistant?**
   - Asking for explanations or copying suggested code.
   - Accepting code suggestions while editing.
   - Delegating file edits to an agent.
