# Before the Workshop

This workshop uses GitHub Codespaces and the Visual Studio Code web interface. The [Setup page](docs/setup.html) walks through the same steps with screenshots. There is no Codespace-deletion section.

## One short rehearsal

Please prepare once before the session, using the [tic-tac-toe starter template](https://github.com/igorsdub/git-tic-tac-toe-template):

1. Choose **Use this template → Create a new repository**. Make your repository public under your own account, fill in **Description**, and tick **Include all branches**. The template now has only `main`, so the copy is just `main`.
2. Open your new repository in a Codespace.
3. Run the readiness check. Open Copilot Chat, choose Ask, type exactly **"What does this repository do?"**, and press Enter. It passes when the answer mentions tic-tac-toe and `BOARD.txt`.
4. Keep your public repository. At the session, the owner adds the partner as a collaborator (see [Slot 1](docs/guide.html#invite)), creates branch `match` on github.com, and only then do both people open fresh separate Codespaces.

No board edit is required during this check. Codespaces and Copilot access are separate. Make sure you can sign in to the email account linked to your GitHub account, because the partner may accept from the invitation email on the same signed-in device.

For current GitHub instructions, see [creating a Codespace from a template](https://docs.github.com/en/codespaces/developing-in-a-codespace/creating-a-codespace-from-a-template). For help with Copilot in VS Code, see [chat with Copilot in your IDE](https://docs.github.com/en/copilot/how-tos/copilot-in-your-ide/chat-with-copilot/chat-in-ide).
