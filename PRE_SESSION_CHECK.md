# Before the Workshop

This workshop uses GitHub Codespaces and the Visual Studio Code web interface. You do not need to install Git or use a terminal. The [Setup page](docs/setup.html) walks through the same steps with screenshots and short videos.

## One short rehearsal

Please prepare once before the session, using the [tic-tac-toe starter template](https://github.com/igorsdub/git-tic-tac-toe-template):

1. Choose **Use this template → Create a new repository**. Make your repository public and keep it under your own account.
2. Open your new repository in a Codespace.
3. Run the readiness check. Open Copilot Chat, type exactly **"What does this repository do?"** in the box that says "Describe what to build", and press Enter. It passes when the answer mentions tic-tac-toe and `BOARD.txt`.
4. Stop the Codespace at github.com/codespaces (stop, not delete).
5. Keep your public repository and Codespace. At the session, your pair chooses one prepared repository, its owner invites the partner, and both people open that repository in separate Codespaces.

No board edit is required during this check. Codespaces and Copilot access are separate; if Copilot Chat is unavailable, note that for the facilitator. The facilitator will help with access during the session.

The SOKENDAI survey is live. Its link is on the Setup page. It is for instructor preparation; it is not part of the readiness check.

For current GitHub instructions, see [creating a Codespace from a template](https://docs.github.com/en/codespaces/developing-in-a-codespace/creating-a-codespace-from-a-template). For help with Copilot in VS Code, see [chat with Copilot in your IDE](https://docs.github.com/en/copilot/how-tos/copilot-in-your-ide/chat-with-copilot/chat-in-ide).
