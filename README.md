# Git Tic-Tac-Toe Workshop

Planning space for a two-hour, beginner-friendly Git and GitHub session. Pairs play tic-tac-toe by making small commits to one shared public repository. The aim is for both people to publish a move and receive their partner's move with `git pull`.

The workshop design and implementation tasks are tracked in GitHub issues. [CONTEXT.md](CONTEXT.md) records the terms used across those issues.

This repository is currently a planning space. The learner template, handout, and game wall have not been built yet.
