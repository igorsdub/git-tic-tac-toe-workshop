# Before the workshop / ワークショップの前に

## English

Hey,

I’d like to know what tools you use in your daily practice of science. For each question, choose the option that best describes your usual practice, even if several apply. The AI question lets you choose more than one.

Igor

### Questions

1. **Which programming language are you most comfortable with?** *(Choose one.)*
   - Python
   - R
   - Julia
   - MATLAB
   - Other: ___

2. **Which of these sounds like your regular work?** *(Choose one.)*
   - Organizing data and making tables in Excel.
   - Editing code in RStudio, VS Code, or another editor.
   - Running tools or commands in a terminal.
   - Other: ___

3. **You’ve changed a research file. Where do you keep its history?** *(Choose one.)*
   - Renamed copies, like `analysis_v2` or `analysis_final`.
   - Version history in Google Drive, Word, or another application.
   - Git or another version-control system.
   - Other: ___

4. **When working on files with other people, what does that look like?** *(Choose one.)*
   - Sending revised copies by email or chat.
   - Working together in a shared document, like a Google Doc.
   - Collaborating through a shared repository on GitHub, GitLab, or Bitbucket.
   - Other: ___

5. **Which AI tools do you use for your work?** *(Optional short answer.)*

   **Helper text:** Anything that might limit your access during the workshop? You can mention that here too.

6. **How do you use AI for your work?** *(Select all that apply.)*
   - Asking for explanations.
   - Generating and copying code.
   - Accepting code suggestions while editing.
   - Asking agents to edit files, run commands, or complete tasks.
   - Coordinating several agents.
   - Other: ___
   - I don’t use AI. *(Select this by itself.)*

7. **Your code needs software packages. What’s your approach?** *(Choose one.)*
   - Install packages when needed.
   - Keep a separate environment for each project.
   - Use a project file to recreate the environment.
   - Other: ___

8. **What helps you check that your code works as intended?** *(Choose one.)*
   - Inspecting figures or numerical results.
   - Checking examples with known results by hand.
   - Running automated tests.
   - Other: ___

9. **You need to repeat a task with several steps. What sounds most like you?** *(Choose one.)*
   - Rerunning each step by hand.
   - Using a script or recipe to run them together.
   - Having a workflow run automatically.
   - Other: ___

10. **What’s your biggest day-to-day struggle with programming right now?** *(Optional short answer.)*

## 日本語

### 質問

1. **最も使い慣れているプログラミング言語は何ですか？** *(一つ選んでください。)*
   - Python
   - R
   - Julia
   - MATLAB
   - その他：___

2. **普段の仕事に最も近いものはどれですか？** *(一つ選んでください。)*
   - Excelでデータを整理したり、表を作成したりする。
   - RStudio、VS Code、その他のエディタでコードを編集する。
   - ターミナルでツールやコマンドを実行する。
   - その他：___

3. **研究用のファイルを変更したとき、その履歴をどのように残していますか？** *(一つ選んでください。)*
   - `analysis_v2` や `analysis_final` のように、名前を変えたコピーを保存する。
   - Google Drive、Word、その他のアプリのバージョン履歴を使う。
   - Gitなどのバージョン管理システムを使う。
   - その他：___

4. **他の人とファイルを使って作業するとき、どのように進めていますか？** *(一つ選んでください。)*
   - メールやチャットで修正版を送り合う。
   - Googleドキュメントのような共有文書を一緒に編集する。
   - GitHub、GitLab、Bitbucketなどの共有リポジトリで共同作業する。
   - その他：___

5. **仕事でどのようなAIツールを使っていますか？** *(任意・短文回答)*

   **補足:** ワークショップ中に利用を制限される可能性があるものがあれば、ここに記入してください。

6. **仕事でAIをどのように使っていますか？** *(複数選択可)*
   - 説明を尋ねる。
   - コードを生成してコピーする。
   - コードを編集中に、提案されたコードを採用する。
   - ファイルの編集、コマンドの実行、作業の完了をエージェントに依頼する。
   - 複数のエージェントを連携させる。
   - その他：___
   - AIは使っていない。 *(この選択肢だけを選んでください。)*

7. **コードでソフトウェアパッケージが必要なとき、どのようにしていますか？** *(一つ選んでください。)*

   - プロジェクトごとに環境を分ける。

   - その他：___

8. **コードが意図どおりに動くかを確かめるとき、何をしていますか？** *(一つ選んでください。)*
   - 図や数値の結果を確認する。
   - 正解の分かっている例を手作業で確かめる。
   - 自動テストを実行する。
   - その他：___

9. **いくつかの手順がある作業を繰り返す必要があるとき、ご自身のやり方に最も近いものはどれですか？** *(一つ選んでください。)*
   - 各手順を毎回手作業でやり直す。

   - ワークフローを自動で実行する。
   - その他：___
