SCDA training week 22 / 23

Best Practices

Collaboration
PRACTICE 01
Always Pull Before You Play

Run git pull before every turn to ensure your local board.txt reflects your partner's latest move.

PRACTICE 02
One Move Per Commit

Stage and commit only your single turn. Keep commit messages descriptive: place X center.

PRACTICE 03
Push Immediately to Unblock

Push right after committing so your partner can immediately pull and continue the game without sync delays.
