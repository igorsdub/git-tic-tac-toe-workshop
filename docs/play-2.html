Agentic Coding

In this session you will get a plan out of your head and into Copilot, then let Copilot build a scoreboard for your game.

Jump to:IntroGrillingScoreboardPlayYour own task

1 Intro

Copilot builds the wrong thing when the plan stays in your head.

You describe an idea. Copilot asks questions until the plan is the one you meant. Then it writes that plan down and builds it.

You do not need to know how to program. You need to know what you want, and you need to answer the questions.

2 Grill Copilot until it writes PLAN.md

The partner who was added as a collaborator drives. The owner of the game repository sits beside them and pushes back when an answer is vague.

Main branch is sacred: don't modify it

That rule is for the game repository. Leave its main branch as it is. The scoreboard is a new repository. Files in that new repository can change.

Open a new repository

The partner creates a new public repository on their own GitHub account. Open it in a Codespace, or on a laptop where Copilot is already signed in.

The game repository has to be public too. You set that when you created it. The scoreboard reads its branches.

Paste this prompt

In Copilot Chat, choose Agent. Paste the prompt below. Replace <link to our game repo> with the web address of your game repository. Answer one question at a time. Do not let Copilot build the site yet.

I need a scoreboard for a tic-tac-toe repository where games are stored on different branches: <link to our game repo>. A website should show the scores between the two players. I want to host it on GitHub Pages. I'm not an expert: guide me through the options one question at a time before building anything.

When you both agree, tell Copilot to write the plan in a file named PLAN.md. Read it. If it is not what you meant, say so and answer the next question.

This file is usually called a PRD (product requirements document), PRD.md. PLAN.md is the plain name we use here.

A skill you can reuse

A skill is a set of prompts saved in a file named SKILL.md. You can use the same skill in a new chat without typing it again. The grill-me skill tells Copilot to interview you until you share one plan. Its prompt is below. You do not have to paste it. The prompt above already asks Copilot to go one question at a time.

Interview me relentlessly about every aspect of this plan until we reach a shared understanding. Walk down each branch of the design tree, resolving dependencies between decisions one by one.

3 Build the scoreboard

Stay in the same chat. Copilot builds the site from PLAN.md and publishes it on GitHub Pages.

Tell Copilot to build the scoreboard and put it on GitHub Pages. The site reads the branches of your public game repository and shows the score between the two players.

If Copilot wants to change the game repository, say no. The scoreboard only reads that repository.

You are done when you can open the Pages site and see a score for the two players.

Stuck?

A finished scoreboard, its plan, and the prompts are in github.com/igorsdub/tic-tac-toe-scoreboard-reference. Open it only if you are stuck.

4 Play a match and watch the score

Both of you play in the game repository. Then look at the scoreboard.

Use a branch whose name has the word match in it, such as the branch you already played on. Take turns the same way as in Git Collaboration: pull, edit one cell, then Commit and Sync. Do not change main.

If that match is already finished, ask Copilot to make a new branch from main with match in the name, and play on that branch.

Open the scoreboard again. The new score can take a few minutes to appear. Reload the page if you still see the old score.

5 Think of your own task

Each person does this. You do not have to build it.

Think of a task from your own work that you could grill an agent on. Tell your partner in one or two sentences.
