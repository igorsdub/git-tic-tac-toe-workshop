# Facilitator Training Notes

## User Learning Profile & Preferences
- **Focus**: Track A - Facilitator Preparation for delivering the 2-hour Git Tic-Tac-Toe Workshop.
- **Audience**: Novices, researchers, and students.
- **Priority**: Flawless live demo execution, timeboxing, and rapid error recovery during pair play.

## Working Notes
- Workshop requires zero programming runtime dependencies for learners.
- Core constraint to defend: protect pair play time. The agenda is in the [Facilitator guide](../FACILITATOR_GUIDE.md#agenda-120-minutes).
- Key pedagogy: Never stage synthetic errors; authentic mishaps are the prime teaching moments.
