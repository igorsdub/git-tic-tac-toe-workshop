Facilitator Quick Reference

Reference Doc: REF-0001 Workshop Duration: 120 Minutes Target: Zero-Stall Delivery

2. Core Teaching Mental Model

The Physical Desk Analogy

Local Repository: A personal clipboard on your desk.
GitHub (origin/main): A shared table in the middle of the room.
"You cannot draw on your partner's clipboard. You fetch the central paper (git pull), mark your move (edit), seal it in an envelope (commit), and send it to the table (push)."

3. The 5-Step Turn Cycle

1. PULL:    git pull origin main
2. EDIT:    Update board.md (mark one empty square [ ] -> [X] or [O])
3. STAGE:   git status && git diff && git add board.md
4. COMMIT:  git commit -m "Move N: [X/O] in square [1-9]"
5. PUSH:    git push origin main  --> Tell partner: "Your turn!"

4. 4-Step Error Triage Protocol

  1. Normalize: "Git is not broken; it is protecting your work." Error messages are status reports.
  2. Read aloud: Have the learner read the last 3 lines of output. The remedy is almost always in the hint.
  3. Triage: Identify symptom from the table below.
  4. Celebrate: Reinforce that committed work was never lost.
Error / Symptom Root Cause Immediate Resolution
[rejected] (fetch first) Forgot to pull before moving or pushed out of turn. Run git pull origin main, check board.md, then git push origin main.
CONFLICT in board.md Both players edited simultaneously without pulling. Open board.md, agree on grid, delete markers (<<<<, ====, >>>>), save, git add board.md, commit, push.
Local changes overwritten by merge Edited board.md locally before running pull. Commit local change first, run git pull --no-rebase origin main, then push.
Permission denied (publickey/auth) Invite not accepted or credential helper stuck. Confirm repo invite accepted. Fallback to GitHub Desktop immediately to save time.
Golden Facilitator Rule
Never deliberately inject artificial merge conflicts or synthetic errors. Real mistakes will happen naturally in every room and provide the best authentic teaching moments.
