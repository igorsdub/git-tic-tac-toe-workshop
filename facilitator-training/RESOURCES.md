# Workshop Facilitation Resources

## Knowledge

- [Facilitator guide (FACILITATOR_GUIDE.md)](../FACILITATOR_GUIDE.md)
  The agenda, pre-session steps, facilitation notes for each phase, registration facts, and a recovery appendix. Use for: session pacing and script reference.
- [Rehearsal guide (REHEARSAL_GUIDE.md)](../REHEARSAL_GUIDE.md)
  Checklist for rehearsing the learner path with two accounts, room and facilitation readiness, and support and recovery steps. Use for: pre-flight checks and technical rehearsals.
- [Learner guide (LEARNER_GUIDE.md)](../LEARNER_GUIDE.md)
  What learners read: pre-session steps, the five-step turn cycle, and the agent-assisted rematch. Use for: understanding the learner's perspective.
- [Pre-session checklist (PRE_SESSION_CHECK.md)](../PRE_SESSION_CHECK.md)
  The Codespaces preparation steps and readiness check learners complete before the session. Use for: diagnosing onboarding friction.
- [Pro Git Book by Scott Chacon and Ben Straub](https://git-scm.com/book/en/v2)
  Canonical reference on Git basics, distributed workflows, and branching. Use for: technical grounding on pull and sync mechanics.

## Wisdom (Communities)

- [Software Carpentry / The Carpentries Community](https://carpentries.org/)
  Pedagogical community pioneering live coding, sticky notes, and participatory workshops for scientific researchers. Use for: evidence-based teaching techniques and novice handling.
- [GitHub Community Discussions](https://github.com/orgs/community/discussions)
  Active educator and developer forum for Git and GitHub classroom workflows. Use for: authentication updates and learner onboarding tips.
