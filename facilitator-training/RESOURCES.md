# Workshop Facilitation Resources

## Knowledge

- [Facilitator Guide (FACILITATOR_GUIDE.md)](../FACILITATOR_GUIDE.md)
  Full 2-hour timeline, live demo script with prepared co-pilot, 4-step error triage protocol, and research transfer discussion points. Use for: session pacing and script reference.
- [Rehearsal & Operational Readiness Guide (REHEARSAL_GUIDE.md)](../REHEARSAL_GUIDE.md)
  Facilitator rehearsal protocol, OS compatibility matrix, contingency workflows, and timed checks ensuring 60+ min pair play. Use for: pre-flight checks and technical rehearsals.
- [Learner Handout (LEARNER_GUIDE.md)](../LEARNER_GUIDE.md)
  Hands-on player guide detailing roles, the 5-step turn cycle, quick command reference, and branch rematch extensions. Use for: understanding the learner's perspective.
- [Pre-Session Setup Guide (PRE_SESSION_CHECK.md)](../PRE_SESSION_CHECK.md)
  Environment checklist for Git, GitHub account privacy, and authentication methods. Use for: diagnosing onboarding friction.
- [Pro Git Book by Scott Chacon and Ben Straub](https://git-scm.com/book/en/v2)
  Canonical reference on Git basics, distributed workflows, and branching. Use for: technical grounding on push/pull mechanics.

## Wisdom (Communities)

- [Software Carpentry / The Carpentries Community](https://carpentries.org/)
  Pedagogical community pioneering live coding, sticky notes, and participatory workshops for scientific researchers. Use for: evidence-based teaching techniques and novice handling.
- [GitHub Community Discussions](https://github.com/orgs/community/discussions)
  Active educator and developer forum for Git and GitHub classroom workflows. Use for: authentication updates and student onboarding tips.
