# Mission: Git Tic-Tac-Toe Workshop Facilitator

## Why
Equip the user to confidently deliver, co-lead, and troubleshoot the 2-hour Git Tic-Tac-Toe Workshop for beginners, researchers, and students, ensuring a zero-stall experience where 100% of pairs publish moves and collaborate smoothly.

## Success looks like
- Confidently lead the 20-minute live demonstration with a co-facilitator without hesitation.
- Diagnose and guide pairs through authentic Git errors (push rejections, merge conflicts, detached/dirty working trees) using the 4-step triage protocol.
- Manage the 120-minute timeline to ensure at least 60 uninterrupted minutes of pair play.
- Successfully project and operate the Game Wall and lead the debrief connecting tic-tac-toe commits to real-world research workflows.

## Constraints
- Keep facilitator preparation focused on classroom delivery, triage reflexes, and mental models rather than deep Git plumbing.
- Must support diverse OS environments (macOS, Windows with Git Bash/PowerShell, Linux, and GitHub Desktop fallback).

## Out of scope
- Advanced Git workflows (interactive rebase, cherry-picking, bisect, submodules).
- Customizing the backend Game Wall codebase during facilitation.
