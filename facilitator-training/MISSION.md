# Mission: Git Tic-Tac-Toe Workshop Facilitator

## Why
Equip the user to confidently deliver, co-lead, and troubleshoot the 2-hour Git Tic-Tac-Toe Workshop for beginners, researchers, and students, ensuring a zero-stall experience where 100% of pairs publish moves and collaborate smoothly.

## Success looks like
- Confidently lead the instructor demonstration with a co-facilitator without hesitation.
- Diagnose and guide pairs through authentic Git errors (rejected Sync Changes, merge conflicts, dirty working trees) using the recovery appendix in the [Facilitator guide](../FACILITATOR_GUIDE.md).
- Run the session to the [agenda](../FACILITATOR_GUIDE.md#agenda-120-minutes) so every pair gets its full pair play time and the rematch starts on schedule.
- Successfully project and operate the Game Wall and lead the debrief connecting tic-tac-toe commits to real-world research workflows.

## Constraints
- Keep facilitator preparation focused on classroom delivery, recovery reflexes, and mental models rather than deep Git plumbing.
- Every learner works in a Codespace in the browser, so operating system differences do not matter.

## Out of scope
- Advanced Git workflows (interactive rebase, cherry-picking, bisect, submodules).
- Customizing the backend Game Wall codebase during facilitation.
